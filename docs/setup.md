# 环境搭建指南

## 前置要求
- Python 3.11+
- Git

## 安装步骤

1. 克隆仓库
git clone git@github.com:scnatpc/quant_trading_lab.git<br>
cd quant_trading_lab

2. 创建虚拟环境
python -m venv cottage<br>
source cottage/bin/activate  # Mac/Linux<br>
cottage\Scripts\Activate.ps1  # Windows<br>

3. 安装依赖
pip install -r requirements.txt
